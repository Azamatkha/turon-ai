Turon-AI API v1
Base URL: http://localhost:8100

Ichki bank AI-chatboti backend'ining REST API ma'lumotnomasi. Har bir endpoint: manzil, so'rov (request), javob (response), kirish huquqi va curl namunasi bilan. Mobil ilova uchun mo'ljallangan.

Kirish (auth) & qoidalar

Auth
JWT Bearer: Authorization: Bearer <access_token>
Token
Login access_token + refresh_token beradi. 401 da /auth/login/refresh.
Format
application/json (fayldan tashqari)
username
kichik harf; 4–60 belgi. password 4–128.
